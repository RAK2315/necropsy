NECROPSY Recover image files nothing can open

Get the picture back from an image file nothing can open.

Image formats outlive the programs that read them. NECROPSY needs no reader for the format: it works out from the bytes alone how the picture is laid out, and checks the answer against every byte.

For archivists, investigators, and anyone holding an image in a format nothing reads any more. It reads PCX, TGA, TIFF, PBM, PGM and PPM, including run-length, PackBits, LZW, Deflate and LZMA data, and files with no header at all.

Open source under the MIT licence. Source, specs and every measured result: github.com/RAK2315/necropsy. Built spec-first with Kiro for Kiroween 2026. Files you examine are analysed in memory and never stored.
